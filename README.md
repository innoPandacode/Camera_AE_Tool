# Camera AE Tool 使用說明  

**版本：v1.3_20240814**

## 專案簡介

IQ AE Tool 是一個用於分析和處理圖片亮度與色彩平均值的工具，提供圖形用戶界面（GUI）來方便用戶選取資料夾並執行自動化分析。此工具能夠計算每張圖片的中心區域亮度並比較其是否在設定的範圍內，最後生成結果並保存分析截圖與日誌檔案。

## 功能介紹

- **圖片分析**：從指定資料夾中載入所有圖片，並對每張圖片進行亮度與色彩的計算。
- **範圍檢查**：確定每張圖片的亮度是否在允許的範圍內。
- **結果輸出**：顯示每張圖片的詳細信息並標示是否通過檢查。生成分析結果截圖並保存到指定的資料夾中。
- **日誌記錄**：分析結果會被記錄在 `result/AE` 資料夾內的日誌檔案中。

## 使用方法

1. **下載與安裝**
   - 下載並解壓縮此專案的執行檔（EXE）。

2. **啟動工具**
   - 執行已解壓縮的 `.exe` 檔案來啟動工具。

3. **選擇資料夾**
   - 點擊 "Select" 按鈕，選擇需要分析的圖片資料夾。

4. **查看結果**
   - 程式會自動處理圖片，並顯示分析結果。結果會顯示在新視窗中，並同時保存到 `result/AE` 資料夾中。

## 注意事項

- 確保所有圖片尺寸一致，否則會出現錯誤。
- 程式只支持以下格式的圖片：`jpg`, `jpeg`, `png`, `bmp`, `tiff`。
